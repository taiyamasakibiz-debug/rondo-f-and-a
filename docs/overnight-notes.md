## 確認してほしいこと

- **Cloudflare の本番ブランチ**：今は `v2/foundation`。v2 を main にマージするときに、Settings → Build → Branch control を `main` に戻す必要がある（GitHub Pages の v1 をどうするかも、そのときに決めたい）
- **ストリークの数え方**：今は「デイリー以外の問題でも、その日に解いた数がノルマに届けば +1」。デイリーのおすすめ 3 問を全部解いたときだけ +1 にしたい場合は教えてほしい
- **スマホの ± ボタン**：数値の入力欄の右端に置いた。押すと先頭に △ が付き、もう一度押すと外れる。実機で押しやすいか見てほしい
- **記述問題の採点方法（方針を変えた）**：設計ドキュメントでは「自己採点」の予定だったが、**キーワードが入っているかで目安の部分点を出す自動採点**にした。自己採点だと「採点後に自分でチェックして確定する」手順が増え、デイリーや認定テストの流れに組み込みにくいため。結果には足りない観点と模範解答を出し、「表現の違いは自動では判定しきれない」と注意書きしている。自己採点がよければ変えられる
- **記述の採点基準**：同業他社比較の記述は、Q1 で自分が選んだ指標ではなく「正解の指標」の観点で採点している（Q1 を間違えても、正しい課題を書く練習になるように）
