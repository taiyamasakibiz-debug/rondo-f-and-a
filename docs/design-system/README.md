静かなテクノロジーに、人の温度を。白とグレーの余白を主役に、薄い水色の空気とデジタルラインで「研究・AI」の気配を足し、オレンジはひとさじだけ置くシステム。コーポレートサイト、プロダクトLP、SNS・OGPなどのクリエイティブに使う。

## 基本姿勢

- **余白で読ませる。** セクション間は `space-10`（112px）、左右は `page-margin`（96px）。詰まって見えたら要素を減らす。
- **白とグレーが8割。** 色で飾らず、面の明暗（`paper` → `haze` → `fog`）で階層をつくる。
- **水色は「空気」、線は「データ」。** 薄い水色のグラデーションとデジタルラインは背景モチーフとしてだけ使い、情報を載せない。
- **オレンジは点。** `ember` は1画面に1か所（CTAの丸、ライン上の点など）。

## 配色比率

| 役割 | トークン | 比率の目安 |
| --- | --- | --- |
| 白 | `paper` | 55% |
| グレー系 | `haze` `fog` `line-soft` `line` `stone` | 27% |
| 薄い水色 | `sky-50` `sky-100` `sky-200`（`sky-wash`） | 10% |
| 黒 | `ink` / `night` | 7% |
| オレンジ | `ember` | 1% |

- 白＋グレーで8割を超えるように組む。黒い面（`night`）は1ページに1ブロック（NightBlock）まで。
- 水色は面積10%を上限に、ヒーロー・ページタイトル帯・研究系カード（`ts-card--sky`）に集める。本文の背景には敷かない。
- `mist`（#9FA9B3）は水色ではなくブルーグレー。黒い面の上の番号・アイブロウ、図版用。

## 薄い水色とデジタルライン（備考）

参考：左上がほぼグレー、下中央にかけて淡い水色が溜まる背景に、白い極細の曲線が束になって斜めに横切るビジュアル。

- 背景は `sky-wash`（`sky-200` → `sky-100` 付近 → `#ECEFF0` のグレー寄りの白、の放射グラデーション）。**参考画像より濃くしない**。最も濃い点でも `sky-200`（#CDDFE7）。
- 単色で水色を敷くなら `sky-50`。`sky-100`・`sky-200` の単色面は作らない。
- 白いページの下端をほんのり水色にしたいときは `sky-wash-soft`。
- デジタルラインの線色：水色の上は `line-digital`（白85%）、白地の上は `sky-300`、黒地の上は白の0.14〜0.25。
- 線は10〜16本、`stroke-hair`（0.7〜1.2pxでばらつかせる）、不透明度は `line-opacity-faint`〜`line-opacity-strong`。左下から右上へゆるいS字で流し、途中で数本が交差・収束する。
- そのまま使える素材：Assets の Patterns にある `lines-white.svg`（水色の上用）と `lines-sky.svg`（白地用）。1290×880、背景は透明。`object-fit: cover` で敷く。
- 球体ワイヤーフレーム（円と楕円の重なり、白 or `ink` の0.1〜0.25）はダーク面・ヒーローの図版として併用可。ラインの束と同じ画面には置かない。
- 仕上げに粒子感を足す場合はごく弱いノイズ（2〜4%）まで。グラデーションの色数は増やさない。

## 正解・不正解（学習アプリ用）

- 正解は透明感のあるミントティール、不正解はローズ。どちらも sky と同じく「淡い面＋白いライン」で見せ、濃い塗りは小さなマークだけにする。
- 面：`correct-50` / `correct-100`、`incorrect-50` / `incorrect-100`。結果画面の背景は `correct-wash` / `incorrect-wash`（sky-washと同じ形）。
- 塗り：`correct` / `incorrect` は○×マークの丸とスコアバーだけ。上の記号は `on-correct` / `on-incorrect`（黒）。白抜きにしない。
- 文字：「正解」「不正解」や英字ラベルは `correct-text` / `incorrect-text`。
- 枠線・装飾：`correct-300` / `incorrect-300`。
- **色だけで伝えない。** 必ず ○／× のマークと「正解」「不正解」の文字を添える（2色は明度が近いので、色覚によっては区別しにくい）。
- 不正解の赤は責める色にしない。大きな赤い面は作らず、淡い `incorrect-50` 〜 `incorrect-100` に留める。`incorrect` と `ember` を隣に並べない。
- この2色は配色比率の外。回答直後のフィードバックと成績表示だけで使い、装飾やブランド表現には使わない。

## タイポグラフィ

- 欧文は `sans`（Satoshi。Webでは Manrope で代替。Satoshi が入った環境では自動で Satoshi）。和文は `ja`（Noto Sans JP → ヒラギノ → 游ゴシック）。手書きアクセントは `script`（Hurricane）。
- 英字の大見出しは字間を詰める：`display` `h1` は `tracking-tight`（-0.05em）。
- 和文の見出しは字間を開く：`h2-ja` `lead-ja` `sub-ja` は `tracking-ja`（0.12em）。
- 英字の小見出しは大文字で大きく開く：`eyebrow` は `tracking-caps`（0.4em）。
- 本文は `body`（17px・行間2.0・0.05em）。長文は `ink-body`、注釈・日付は `ink-muted`。
- キービジュアル（SkyKeyVisual、SocialSquare）の英字タイトルだけは Regular（400）・-0.03em で細く大きく。ほかの英字見出しは700。
- 見出しの型は「番号＋英字＋和文サブ」（SectionHeading）。例：`01` Our Vision／ビジョン。
- `script` は1画面に1回、短い英語フレーズだけ、`ember-text` で。

## 言葉づかい

- 英字は短く言い切る（Title Case。アイブロウとタグは大文字）。和文は「〜する。」と静かに言い切り、感嘆符を使わない。
- 日付は `2026.10.01`。数字の実績は出典と時点を必ず併記し、無ければ `[000]` のまま置く。
- 絵文字は使わない。

## 形・余白・グリッド

- ボタン・ナビ・タグは必ず `radius-pill`。カードは `radius-xl`（36px）、night上のカードは `radius-lg`、パネルは `radius-md`。
- 余白は `space-1`〜`space-10`（4・8・12・16・24・32・48・64・96・112）から選ぶ。
- 12カラム、ガター `grid-gutter`、左右 `page-margin`。見出し4カラム：本文8カラムが基本。
- 影は使わない。面の明暗と1pxの `line` で区切る。ナビだけ半透明＋blur。

## アイコン・ロゴ

- アイコンは矢印（→）だけ。1.6pxの線、`currentColor`、丸い台（Button の `ts-btn__dot`、SeeMore の円枠、Card の `ts-card__go`）に載せる。
- ロゴは収録していない。社名は英字大文字・字間0.3em・800で組む（例：TESSERA）。実在企業のロゴやマークは模写しない。

## アクセシビリティ

- 文字色は各トークンの usage にある面の上でだけ使う（どれも4.5:1以上。`ember-text` は `paper` 上でちょうど4.5:1なので `fog` 上では24px以上のみ）。
- `ember` 地の文字は `#121213`（6.9:1）。白文字は不可。
- フォーカスは `focus`（2px実線＋2pxオフセット）。
- 水色の上の小さい注釈は `ink-body` 以上の濃さにする。

## 使い方

- トークンは tokens.css の CSS 変数（`var(--paper)` など）。コンポーネントは `components/bundle.css` のクラス（`ts-` 接頭辞）。ルート要素に `ts` クラスを付ける。
- 黒い面の中では親に `ts-on-night` を付けると、ボタン・リンク・見出しが反転する。
